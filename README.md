# Fixora Crew — aggiornamenti Android

Questo repository contiene **solo i file di rilascio** dell'app Fixora Crew (APK firmato e `update.json`).
L'app controlla qui le nuove versioni e le installa solo dopo la conferma dell'utente.
Nessun codice sorgente, nessuna chiave, nessun dato dei clienti.
